Hứng Sao (Demo)

Game arcade nhỏ minh họa tính năng chơi trực tiếp trên trình duyệt — điều khiển giỏ hứng sao và né bom.

Nhấp vào khung game để điều khiển bằng bàn phím.

Giới thiệu

Hứng Sao là game demo để minh họa tính năng chơi game ngay trên web của trang này.

Cách chơi

  • 🖱️ Chuột / chạm: di chuyển giỏ theo con trỏ
  • ⌨️ Bàn phím: phím ← → hoặc A / D
  • ⭐ Hứng sao để ghi điểm, 💣 chạm bom sẽ mất một mạng — mất 3 mạng là thua!

Ghi chú phát triển

Game càng chơi lâu thì sao rơi càng nhanh và bom xuất hiện nhiều hơn.
